# members/ — personal sandboxes

Each folder here is a **private scratch space** for one team member: notebooks,
experiments, model-download scripts, throwaway tests, notes. Dump WIP here freely.

⚠️ **This is NOT where the working code lives.** The real pipeline is in
`backend/app/` and `frontend/`. Your production code goes in the file you *own*
(see the table), not in your sandbox — otherwise nothing connects.

| Folder | Member | Owns (production file) | Part |
|--------|--------|------------------------|------|
| `members/yedige/` | Yedige (you) | `backend/app/agent.py`, `mcp_config.py`, `main.py`, `frontend/` | 3 & 4 |
| `members/dana/`   | Dana | `backend/app/asr.py` | 1 · ASR / STT |
| `members/janat/`  | Janat | `backend/app/tts.py` | 2 · TTS |
